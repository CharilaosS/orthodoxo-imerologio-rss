# Ημερολόγιο Ορθοδοξίας — RSS

Ένα post την ημέρα για RSS readers (π.χ. News Explorer):
ημερομηνία, νηστεία, Συναξαριστής και αποσπάσματα από τους λόγους του π. Συμεών
([agia-triada-panorama.gr](https://agia-triada-panorama.gr)), μαζί με τον πρώτο άγιο της ημέρας
και σύντομη βιογραφία από το [saint.gr](https://www.saint.gr).

Feed: https://charilaoss.github.io/orthodoxo-imerologio-rss/feed.xml

Ενημερώνεται κάθε πρωί από το GitHub Action `daily.yml` (και χειροκίνητα με «Run workflow»).
Γραμματοσειρά: Fira Sans Extra Condensed (SIL OFL, `fonts/OFL.txt`).
